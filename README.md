# Foundry Connect — design preview

A **UI/UX design prototype** of Foundry Connect, the advisor web portal for
[Foundry](https://github.com/spikeatone/Foundry) (a decade-long mentor for teens entering the skilled
trades). This is a static mockup: all names, schools, wages, and contact details are **fictional sample
data** for design purposes — no real person's information appears here.

Live: https://spikeatone.github.io/foundry-connect-preview/

_Not a functioning product; not connected to any real student data._
